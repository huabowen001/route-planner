# 北京出行路线规划项目

## 项目简介
这是一个全面的北京出行路线规划工具集，提供了从特定起点到终点的多种交通方式规划、距离测量和天气预报信息。所有数据基于高德地图API实时获取，确保信息的准确性和时效性。

## 使用指南

### 如何选择最佳路线
1. **时间优先**: 选择驾车或公共交通最快方案
2. **成本优先**: 选择步行或公共交通
3. **舒适优先**: 选择驾车或公共交通（避免步行过多）
4. **天气考虑**: 恶劣天气避免步行，选择公共交通或驾车

### 数据更新
1. **路线数据**: 基于实时地图数据
2. **天气数据**: 每日更新
3. **距离测量**: 理论计算值

### 注意事项
1. 实际出行时间可能因交通状况而变化
2. 天气预报仅供参考，出行前请查看最新预报
3. 建议使用导航APP获取实时路线指引

## 技术实现
- **地图数据**: 高德地图API
- **天气数据**: 高德天气API
- **距离计算**: 球面距离公式（Haversine）
- **文件存储**: GitHub仓库
